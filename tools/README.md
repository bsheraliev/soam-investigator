# Скрипты сборки данных из QRG

Нужны только при пересборке `data/taxonomy.json` и `data/cases/*.json` из PDF. В приложении не используются.
Python 3.12, пакет `pymupdf` (установлен системно). Пути внутри скриптов — к рабочей папке сессии, при повторном запуске поправить.

| Скрипт | Что делает |
|---|---|
| `extract.py` | текст PDF постранично (pypdf) — для чтения |
| `chart.py` | снимает со страниц 49–51 PDF (печатные 47–49) блоки схемы и линии связей → `chartNN.json` |
| `build_en.py` | английский скелет таксономии из текста QRG (тяжесть, OSF, контекстные условия, барьеры, вопросы, SMARTER, QA) |
| `add_shelo.py` | добавляет SHEL/O, элементы SOAM, состояния барьеров; выгружает строки для перевода |
| `merge.py` | вливает русский перевод и пишет `data/taxonomy.json` |
| `gen_cases.py` | строит три кейса из `chartNN.json` → `data/cases/` |

Порядок: `extract.py` → `chart.py` (×3) → `build_en.py` → `add_shelo.py` → перевод → `merge.py` → `gen_cases.py`.
