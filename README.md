# SOAM Investigator

Приложение для расследования авиационных событий по методологии **SOAM** (Systemic Occurrence Analysis Methodology, EUROCONTROL) и для проактивной оценки рисков по методике **PIRATe**. Ведёт расследователя по шагам и не даёт закрыть дело, пока не выполнены обязательные требования методологии.

- **Приложение:** https://bsheraliev.github.io/soam-investigator/ (Chrome / Edge, работает офлайн, данные хранятся в браузере).
- **Методология:** EUROCONTROL. *Systemic Occurrence Analysis Methodology (SOAM) Quick Reference Guide*, Version 3.0, April 2023. © EUROCONTROL. Английские формулировки таксономии воспроизведены дословно для некоммерческого использования с указанием источника; русский перевод — наш. Сам документ в репозиторий не входит.
- **Язык интерфейса:** русский (таджикский и английский — после приёмки).

## Что умеет
1. Регистрация события, тяжесть A–E (QRG стр. 7) и рекомендация о расследовании.
2. Сбор фактов по модели SHEL/O с подсказками, вложения, открытые вопросы.
3. Хронология с привязкой фактов.
4. Тест вклада и классификация по четырём элементам SOAM (участие человека, контекстные условия, организационные и системные факторы, барьеры) с контрольными вопросами и обязательным подтверждением.
5. SOAM Chart (4 колонки + исход), связи, экспорт SVG / PNG.
6. Меры безопасности: каждый отсутствующий или отказавший барьер и каждый OSF должен быть закрыт мерой; SMARTER.
7. Контрольный список качества (12 пунктов), ключевые уроки; «Завершено» — только при полной готовности.
8. Отчёт (печать в PDF), экспорт и импорт дела в JSON, реестр мер со сроками, статистика по кодам OSF, глоссарий QRG.
9. Режим PIRATe — гипотетический сценарий «наше следующее происшествие» тем же процессом.
10. По желанию — сервер организации: пользователи и роли, передача дел, журнал действий, резервная копия (`server/`).

## Запуск локально
Приложение — статические файлы, без сборки:
```powershell
python -m http.server 8150 --bind 127.0.0.1
```
Открыть http://127.0.0.1:8150/ ; тесты приложения — http://127.0.0.1:8150/tests/ (в браузере, без зависимостей).

Сервер (необязательно): см. [server/README.md](server/README.md) — `npm install`, `npm test`, `npm start`; развёртывание на Render + Neon через `render.yaml`.

## Структура
```
index.html, sw.js, manifest.webmanifest   — оболочка PWA
css/app.css
js/app.js            — роутер, service worker
js/db.js             — IndexedDB
js/rules.js          — бизнес-правила SOAM (чистые функции, покрыты тестами)
js/bundle.js         — экспорт/импорт дела
js/modules/          — экраны: событие, факты, хронология, сортировка, схема, меры, QA, отчёт, реестр, сервер
data/taxonomy.json   — таксономия SOAM (en дословно из QRG, ru, tj)
data/cases/          — три опубликованных в QRG кейса (стр. 47–49)
docs/                — состояние проекта (STATE.md), решения, бэклог, сценарий приёмки
server/              — сервер организации (Node 24 + Express, SQLite / Postgres)
tests/               — тесты приложения в браузере
```
