Коллеги, добрый день.

Прошу посмотреть приложение для расследования авиационных событий по методологии SOAM (EUROCONTROL SOAM Quick Reference Guide V3, 2023) и дать замечания.

**Адрес:** https://bsheraliev.github.io/soam-investigator/ — открывать в Chrome или Edge на компьютере. Регистрации нет, все данные остаются в вашем браузере, на сервер ничего не уходит.

**Что это.** Приложение ведёт расследователя по шагам SOAM: регистрация события и тяжесть → сбор фактов по SHEL/O → хронология → тест вклада и классификация (участие человека, контекстные условия, организационные факторы, барьеры) → схема SOAM → меры безопасности (SMARTER) → контрольный список качества → отчёт в PDF. Приложение не даёт завершить дело, пока каждый отсутствующий или отказавший барьер и каждый организационный фактор не закрыт мерой. Термины и контрольные вопросы — дословно из QRG, с русским переводом. Есть режим PIRATe для проактивной оценки рисков по гипотетическому сценарию.

**Что прошу сделать.** Пройти сценарий приёмки (прилагаю, 10 шагов, около часа) на любом учебном или обезличенном событии и заполнить таблицу замечаний в конце. Особенно важны ответы на четыре вопроса по методологии в конце сценария: статусы дела, хронология, обязательные поля регистрации по национальным правилам, качество русского перевода терминов.

**Как смотреть схему QRG для сверки.** На странице «Тестовые кейсы» загрузите кейс «Гамильтон 2015» и откройте вкладку «Схема» — она должна совпадать со схемой на стр. 49 руководства.
