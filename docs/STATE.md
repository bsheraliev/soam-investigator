## Этап 4.1 — сервер и роли (2026-10-10), в `main` и на проде (sw 0.4.1); сервер ещё не развёрнут

### Сделано
- **Сервер** `server/` (Node 24 + Express 5, без сборки): организация → пользователи с ролями admin / investigator / reader → дела; дело хранится целиком как пакет JSON формата экспорта и проверяется той же функцией `validatePortable`, что в приложении; запись с оптимистической блокировкой (`baseVersion` → `409`); журнал действий (регистрация, вход, дела, пользователи); пароли scrypt, сессии по токену (в БД только SHA-256), срок 30 дней; CORS только для адресов из `ALLOWED_ORIGINS`.
- **БД**: SQLite через встроенный `node:sqlite` (локально и в тестах) или Postgres по `DATABASE_URL` (Render + Neon); один слой `src/db.js`, миграции по номеру версии.
- **Тесты сервера** `node --test` без зависимостей: 7 сценариев (health и CORS, регистрация/вход, пользователи и роли, дела и конфликт версий и изоляция организаций, журнал, смена пароля, закрытая регистрация). GitHub Actions `.github/workflows/test.yml` гоняет их на каждом пуше.
- **Экран «Сервер»** в приложении (`#/sync`, пункт меню «Сервер»): вход по адресу сервера + почте + паролю, регистрация организации (для первого администратора), список дел на сервере с «Получить», список локальных дел с «Отправить» и состоянием версии; на вкладке «Событие» кнопка «Отправить на сервер» и строка «На сервере: версия N». Без входа приложение ничего никуда не отправляет (экран это явно говорит).
- **Развёртывание**: `render.yaml` (Blueprint, бесплатный тариф, Node 24) + `server/README.md` с шагами для владельца (Neon → Render → `DATABASE_URL` → регистрация первого администратора → закрыть регистрацию).
- Версии: APP 0.4.0, CACHE 0.4.1, сервер 0.4.0. Тесты: приложение 31/31, сервер 7/7.

### Проверено
- Сервер локально на 8161 (SQLite в памяти) + превью 8150: регистрация организации с экрана «Сервер» → отправка кейса Гамильтон (версия 1) → повторная отправка (версия 2) → удаление локальной копии → «Получить» восстановило дело с 28 фактами и отметкой версии 2 → на вкладке «Событие» кнопка и строка «На сервере: версия 2». Выход — сессия удалена. Тестовый сервер остановлен, данных не осталось (память).
