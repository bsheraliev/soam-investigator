- **Открытые вопросы по фактам** (QA № 4): у факта флаг «нужны дополнительные данные» + вопрос (в форме факта и в сортировке); список на вкладке QA с кнопкой «Закрыть»; раздел в отчёте; готовность требует 0 открытых.
- **Ключевые уроки и распространение** (QA № 12): поля дела на вкладке QA, раздел в отчёте; готовность требует хотя бы один урок.
- **Быстрая сортировка**: после «да» — кнопки HI / CC / OSF / BAR на карточке факта, форма сразу с нужным элементом и контрольным вопросом; кнопка «Следующий неотсортированный». Подтверждение — на каждую классификацию (правило 2 сохранено).
- **Авто-связи**: барьер → исход ставится при сохранении классификации; на схеме кнопка «Предложить связи» — по фактам, привязанным к одному событию хронологии, между соседними уровнями (OSF→CC→HI→BAR) + недостающие барьер → исход. Удаление классификации удаляет её связи.
- Версии: APP 0.3.1, CACHE 0.3.2. Тесты: 27, все проходят.

### Проверено
- Превью: подсказка Element Review открывается; быстрые кнопки появляются только у фактов, прошедших тест вклада; классификация BAR → связь к исходу создана автоматически; открытый вопрос блокирует готовность, после «Закрыть» — ✓; уроки сохранены → ✓; «Предложить связи» добавила связь по событию хронологии (1 → 2).
