# Состояние проекта

## Этап 1 (MVP) — сделано (2026-10-10), ветка `claude/etap-1` (от `claude/etap-0`)

### Сделано
- `js/rules.js` — правила в чистом виде: правило 1 (тест вклада), правило 2 (подтверждение контрольного вопроса + подкатегория), переходы статусов («Завершено» заблокировано до этапа 2), тяжесть обязательна для инцидента, лимит вложения 5 МБ, сортировка хронологии.
- Реестр дел: кнопка «Новое дело», поиск по названию/месту.
- Карточка события: название, дата/время, место, тип (АП/инцидент), тяжесть A–E с определениями из QRG (стр. 7), решение о расследовании с обоснованием, исход, статус.
- Дело на вкладках: Событие · Факты · Хронология · Сортировка · Элементы SOAM.
- Факты: текст, элемент SHEL/O с раскрывающимися подсказками из QRG (стр. 13–15), источник, вложения (Blob в IndexedDB, до 5 МБ на файл).
- Хронология: время, описание, привязка к фактам; сортировка по времени.
- Сортировка: тест вклада (да/нет); «нет» → «прочие вопросы безопасности»; «да» → классификации (несколько на факт): элемент HI/CC/OSF/BAR, контрольный вопрос 1–4 с обязательной галочкой, подсказки — формат HI (QRG стр. 45), 5 категорий КУ с примерами, 12 OSF с определением/признаками/последствиями, 6 типов барьеров с примерами + состояние absent/failed/worked. Классификации тестовых кейсов редактируются (можно проставить состояние барьера).
- Словари RU/EN/TJ — 159 ключей (TJ — Haiku, не вычитан носителем). `sw.js` CACHE_VERSION 0.1.1, `APP_VERSION` 0.1.0.
- Тесты: 21, все проходят.
