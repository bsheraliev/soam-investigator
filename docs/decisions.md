# Журнал решений

Одна строка на решение, с датой. Новые сверху.

- 2026-10-10 — Связи в кейсах: «шина» на схеме QRG (одна линия соединяет несколько блоков) развёрнута в попарные связи между соседними уровнями (OSF→CC→HI→BAR→исход); пунктир сохранён как `style: dotted`. Поэтому у Гамильтона 135 связей.
- 2026-10-10 — Состояние барьера в кейсах не проставлено (`barrierState: null`): схемы QRG не различают absent/failed.
- 2026-10-10 — «Другие системные факторы» (пунктирные блоки EE на схемах) — это OSF с флагом `otherSystem: true`, отдельного элемента SOAM нет.
- 2026-10-10 — Узел схемы = классификация (`classification`), не факт: один факт может иметь несколько классификаций, связи идут между классификациями; связь барьер→исход хранится как `toId = occurrence.id`.
- 2026-10-10 — Перевод таксономии на русский делали 4 параллельных субагента Haiku (по инструкции экономии); проверка ключей — скриптом, качество — выборочно.

- 2026-10-10 — Нумерация страниц QRG: везде используем печатный номер (внизу страницы); номер страницы в PDF-файле = печатный + 2.
- 2026-10-10 — Таксономия: английские формулировки берутся из QRG дословно (скрипт извлекает текст из PDF), русский — машинный перевод с ручной сверкой, таджикский — `tj_status: todo` до проверки владельцем.
- 2026-10-10 — Тестовые кейсы: только три опубликованные схемы из QRG (стр. 47–49); узлы и связи сняты с векторной графики PDF, текст дословно.
- 2026-10-10 — Тяжесть события: порядок A, B, C, E, D как в QRG (стр. 7), E («нет непосредственного влияния») выводится перед D («не определено»).
- 2026-10-10 — Хранилище: IndexedDB, 7 хранилищ по модели данных из CLAUDE.md, версия схемы — целое число в `js/db.js`.
- 2026-10-10 — Роутер: хеш-маршруты (`#/occurrence/<id>/facts`), чтобы работать с GitHub Pages без серверной настройки.
